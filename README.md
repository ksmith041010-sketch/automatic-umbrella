# 🎮 GuessTheNumber

An interactive command-line number guessing game built in Python.

**Version:** 1.0.0

## 📖 About the Project

**GuessTheNumber** is a command-line number guessing game built in Python as part of my software engineering learning journey.

What began as a simple guessing game evolved into a feature-rich project that demonstrates core programming concepts, including functions, loops, input validation, game state management, randomized gameplay, and Git/GitHub version control.

The project was developed incrementally, with each phase introducing new mechanics and improvements while reinforcing software development best practices.

The project is available both as Python source code and as a standalone Windows executable.

---

## ✨ Features

- 🎮 Multiple difficulty levels
- ❤️ Lives (Heart) system
- 💰 Hint token system *(foundation implemented for future gameplay)*
- 🔥 Hot and Cold feedback
- 📈 Hotter/Colder guidance after each guess
- 🎯 Score tracking
- 🏆 Achievement system
- 📈 Combo/Streak tracking
- 😀 Emoji-enhanced game interface
- 🛡️ Input validation to improve gameplay stability
- 🎲 Randomized secret number each round

---

## 🛠️ Technologies Used

- **Python 3** – Core programming language
- **Git** – Version control
- **GitHub** – Repository hosting and version management
- **PyInstaller** – Packaged the game into a standalone Windows executable

---

## ▶️ Running the Game

### Option 1 — Windows Executable

Download **Version 1.0.0** from the **Releases** section and run:

`GuessTheNumber.exe`

No Python installation is required.

### Option 2 — Run from Source

Clone the repository and run:

```bash
python Guessing_Game.py
```

Python 3 is required.
